# Experiment 3.1 – Web Applications Using Servlets and JSP

## 📚 Overview
This project contains three parts:
1. **User Login (Servlet + HTML Form)**
2. **Employee Records (Servlet + JDBC)**
3. **Student Attendance Portal (JSP + Servlet + Database Integration)**

## ⚙️ Technologies Used
- Java Servlet (Jakarta EE)
- JSP
- JDBC
- MySQL Database
- Apache Tomcat Server
- Eclipse IDE
